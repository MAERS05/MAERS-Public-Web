## 初始状态

这是独立的空白模板：文章、相册照片、音乐列表、收藏、标签、更新动态和加密内容均已清空。首页沿用六张导航卡片：Lens、M&V、Games、Notes、Literature、Record；空间由顶部 SPACE 进入，相册初始为空。

不包含个人项目的 Git 历史、密钥环、恢复码包裹槽、媒体凭据、账号缓存、数据库、备份、个人录屏和开发截图。原项目中的公开与加密内容都没有复制。

启动后台后会生成本机数据库与锁文件，它们已被 Git 忽略。分发整个文件夹前应移除 `_studio/.local/`、`__pycache__/` 和 `data/*.db*`；不要把日后填写的凭据或新增的私人内容打包。

## 首次运行

安装 Python 依赖后执行 `python -B _studio/server.py`，访问 `http://127.0.0.1:8001/admin`。静态站点构建运行 `node _studio/tooling/build-site.mjs`，输出目录是 `dist/`。

Windows 可以运行 `python _studio/tools/build_desktop_app.py --skip-icon` 重建 `Maersy.exe`。可移植启动器与项目放在一起使用，不固化作者电脑路径，默认不复制到系统桌面。管理服务与个人版使用不同端口，浏览器存储也按来源隔离。

## 配置自己的服务

- 默认媒体后端为本机目录，不要求 R2；公开图片基址为空，使用站点内路径。
- 中继地址、GitHub 仓库与令牌默认为空。需要云同步时，部署自己的 Worker 并在后台填写配置；不会连接原作者的服务。
- 联系页面默认禁用发送。使用前设置自己的接收地址。
- 加密内容为空且没有预置主密码；首次使用时创建自己的密码与恢复材料。不得将 `_studio/.local/` 和媒体凭据加入 Git。
- 发布前检查自己的 `data/` 与 `photos/`：这些目录是内容真源，添加的公开内容可能随 Git 与站点一起发布。
