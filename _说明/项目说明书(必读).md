# Maersy - Personal Web Ecosystem

Maersy 是一个追求极致轻量、原生体验的个人数字花园生态系统。它集成了内容管理系统 (CMS)、数字相册、音乐播放器、3D 文学流、游戏库、影视库与多维空间于一体，完全基于原生 Web 技术构建。

## 1. 项目简介

Maersy 摒弃了 React/Vue 等重型前端框架与复杂的打包构建链路，回归 Web 本源。

- **核心目标**: 提供一个既能作为**极速纯静态网站**发布展示（Viewer Mode），又能通过**本地原生桌面端**（`Maersy.exe`）或云端同步进行全功能内容创作与数据治理（Admin Mode）的双模系统。

## 2. 核心功能

### 📝 CMS (内容管理系统)
- **文件驱动架构**: JSON 目录树与 Markdown 正文为持久化真源，SQLite 仅为可重建缓存；支持使用 VS Code / Typora 等外部工具直接编辑正文。
- **全本地化 Vditor 阅读器**: 使用 `Vditor.preview`，支持思维导图 (Markmap)、ECharts 图表、KaTeX 数学公式、Mermaid 流程图及 `H1-H6` 动态目录大纲；引擎缺失时显示 Markdown 纯文本。
- **内链拦截与跨模块漫游**: 支持同模块 `.md` 相对路径无刷新跳转，以及通过 `?openNote=标题` 参数实现跨模块深度直达。
- **多模标签系统**: 标签分类采用 `data/tags/*.json` 物理文件驱动，支持 `AND`（交集）、`OR`（并集）、`DEL`（排除）三种筛选模式及右键快捷运维。
- **端到端加密 (E2EE)**: 基于 Web Crypto API (`AES-GCM` + `PBKDF2`) 实现私密笔记与加密密钥环管理，静态部署下依然保障隐私安全。

### 🖼️ Album & Photos (相册与图库)
- **自适应瀑布流与沉浸灯箱**: 高性能瀑布流网格展示，配备支持缩放、平移、键盘导航的灯箱查看器。
- **三级图像存储**: 上传时自动生成 `Origin` (原图)、`Preview` (1600px AVIF 高清预览) 和 `Thumbnail` (400px WebP 列表缩略图)，兼顾画质与加载速度。
- **私密相册锁与云存储**: 相册记录在浏览器加密，原图、预览图和缩略图迁入私有存储并经令牌鉴权读取；图片文件本身尚未端到端加密。媒体后端兼容 Cloudflare R2、S3 及本机目录，配置见[数据保障与存储迁移](数据保障与存储迁移.md)。

### 🎵 Music (音乐播放器)
- **画中画 (PiP)**: 支持悬浮窗歌词与播放控制。
- **跨页无缝续播**: 播放状态实时持久化至 `LocalStorage`，切换页面自动恢复进度。
- **元数据智能抓取**: 支持通过 Bilibili BV 号自动拉取封面、分 P 列表与时长信息。

### 📚 Literature (文学)
- **Flow Engine 2.0 (流动引擎)**: 参数化自适应 3D 流动路径，根据视口宽度、间距与书籍数量动态计算回路与离屏跑道，实现零闪烁循环漫游。
- **沉浸式阅读**: 点击书籍平滑切入带目录大纲的专注阅读模式。

### 🎮 Games (游戏库)
- **双视图架构**: 默认展示 `Playing` 随机抽取沙盒视图（抽取结果自动持久化），支持一键切换至 `Played` 2:3 竖版海报网格视图。
- **统一后台**: 深度复用 CMS 管理内核，通过 `admin-cms.html?module=games` 统一管理。

### 🎬 Videos (影视库)
- **海报流布局**: 采用标准 2:3 竖屏影视海报网格。
- **Music & Videos 联动**: 页面标题内置跨模块交互跳转，打通视听娱乐维度。

### 🌌 Space (多维空间)
- **双轨存储**: 结合 `space-tree.json`（树状层级）与 `space-collections.json`（元数据集合），支持输入 URL 自动抓取网站标题与 Favicon。

### 📲 PWA 与离线下载
- **桌面/移动端安装**: 内置 `manifest.json`，支持作为 PWA 应用安装至系统桌面或手机主屏幕。
- **全站离线包下载**: 右下角内置离线下载浮窗（`offline-download.js`），支持一键缓存全站框架资源、JSON 索引、Markdown 正文、WebP 缩略图及可选的 AVIF 高清大图，断网环境下依然可完整浏览。

### 🚀 部署、同步与版本控制
- **三级缓存穿透 (`maers-version-controller.js`)**: Service Worker 支持 `files`（单文件热修）> `groups`（按模块分组版本）> `default`（全站兜底）三级版本匹配，修改版本号即可精准穿透 CDN 缓存。
- **GitOps 与多端云同步**: 后台内置本地 Git 状态检测与一键 Commit/Push，同时支持通过 Cloudflare Worker / GitHub API / R2 在移动端与桌面端之间同步内容变更。

## 3. 技术架构

### 前端 (Frontend)
- **语言**: 原生 ES6+ JavaScript (`import` / `export` 模块化，后缀统一为 `.module.js`)
- **架构**: 零业务全局污染 + 显式依赖注入 + 适配器模式（Photos/Space 复用 CMS 组件）
- **样式**: CSS3 Variables 昼夜双模主题、四层 CSS 架构、`custom/zmobile adaptation/` 物理隔离移动端极速降级方案
- **防闪烁**: `<head>` 顶部同步执行 `shared/flash-guard.js`，消除深浅色切换与首屏加载闪烁 (FOUC)

### 后端 (Backend - Admin Mode)
- **语言**: Python 3.10+
- **核心引擎**: `_studio/` 目录下仅监听回环地址的多线程 HTTP 服务 (`ThreadingHTTPServer`)
- **依赖自愈**: `server.py` 启动时自动通过 `ensure_dependencies()` 极速检测并按需安装第三方依赖（`Pillow`、`pillow-avif-plugin`、`boto3`）
- **数据库**: SQLite (`data/cms.db`, `data/gallery.db`) 仅作轻量索引，所有内容与静态快照均落地为物理文件 (`.md` / `.json`)

## 5. 运行与部署

### 5.1 访客模式 (Viewer Mode)
纯静态架构，可直接部署至 GitHub Pages、Vercel、Cloudflare Pages，或使用任意静态 HTTP 服务器预览。

### 5.2 管理模式 (Admin Mode)
通过项目根目录的原生桌面启动器 **`Maersy.exe`** 一键运行：

1. **双击启动 `Maersy.exe`**（或桌面快捷方式）：
   - 启动器会在后台无黑框静默拉起 `_studio/server.py` 服务。
   - 服务端自动检测 Python 环境依赖（`Pillow`、`pillow-avif-plugin`、`boto3`），缺失时自动静默安装。
   - 服务就绪后，自动以独立桌面应用窗口（Chromium `--app` 模式）打开后台管理门户 `http://localhost:8001/admin-portal.html`。
2. **单实例唤醒与自动停服**：
   - 若应用已在运行，再次双击 `Maersy.exe` 会直接激活并置顶已有窗口，不会重复启动进程。
   - 直接关闭后台应用窗口，启动器会自动终止后台 Python 服务并释放 `8000` 端口。
3. **命令行调试模式（可选）**：
   - 开发者也可在项目根目录执行 `python _studio/server.py` 查看实时双语终端日志。

## 6. 管理员指南 (Admin Guide)

### 6.1 后台门户集成工具 (`admin-portal.html`)
所有日常维护与发布工具均已内聚至后台管理门户顶部工具栏，无需运行任何外部批处理脚本：
- **🧹 清理垃圾**: 一键扫描全站 Markdown、HTML、JSON 与数据库引用，自动清除 `photos/` 下未被引用的孤儿图片/附件、清理孤儿 `.md` 文档并修复数据库幽灵记录。
- **📦 Git 提交推送**: 实时检测本地 Git 仓库变更列表，填写备注即可一键完成 `git add`、`commit` 与 `push`。
- **☁️ 多端云同步**: 配合 Cloudflare Worker / GitHub / R2 同步移动端与桌面端的增量修改。
- **🔐 密钥与隐私管理**: 配置主密码与密钥环（Keyring），加密私密正文、文章和相册记录，并迁移相关图片到私有存储；首页卡片加锁仅保护导航记录，不自动加密目标页面。
- **📢 更新日志管理**: 可视化编辑全站 `What's New` 更新公告（持久化至 `data/changelog.json`）。

### 6.2 核心创作工作流
- **统一阅读器与源码保存**: 在各模块后台（如 `/admin-cms.html?module=notes`）创建内容，使用阅读器源码抽屉编辑并保存 Markdown；成功后更新 `.md`、JSON 真源及 SQLite 缓存，不再提供内置 Vditor 所见即所得编辑器。
- **本地编辑器协同**: 阅读器的“编辑”按钮可打开系统默认 Markdown 软件；外部修改保存后，切回管理窗口触发正文刷新，未保存的源码草稿会保留。
